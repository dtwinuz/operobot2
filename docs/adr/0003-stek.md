# ADR-0003 · Stek: Node 24 + TypeScript, Fastify, PostgreSQL, React + Vite

**Holat:** qabul qilindi, 2026-11-04.

**Qaror.** API — Fastify 5 + `pg` (ORM yo'q, SQL ochiq) + zod. Panel — React 19 + Vite, o'z hash router'i, UI kutubxonasi yo'q (lucide ikonlar). Real vaqt — SSE.

**Nega.** operobot (dialer va sayt) bilan bir til va bir xil asboblar: bitta jamoa ikkala repoda ishlaydi. ORM'siz SQL RLS va hisobot so'rovlarini ko'rinadigan qiladi. SSE WebSocket'dan sodda va proxy (Caddy) orqali muammosiz.

**Oqibat.** Migratsiyalar qo'lda yoziladigan `.sql`. Hajm oshsa navbat va `LISTEN/NOTIFY` ([02](../02-arxitektura.md#kengayish)).
